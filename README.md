# MenuBarTidy

메뉴바 아이콘이 많아서 노치에 가릴 때, 안 쓰는 아이콘을 숨기고 필요할 때 **아래로 펼쳐서** 쓰는 가벼운 macOS 메뉴바 정리 앱입니다.

A tiny macOS menu bar manager: hide icons behind a divider and open hidden or notch-covered icons from a drop-down grid.

- macOS 14 (Sonoma) 이상, 애플 실리콘·인텔 모두 지원
- Swift 한 파일, 외부 라이브러리 없음

## 설치

1. [Releases](../../releases)에서 `MenuBarTidy-x.y.zip`을 받아 풀고, `MenuBarTidy.app`을 **응용 프로그램** 폴더로 옮깁니다.
2. 처음 열면 "확인되지 않은 개발자" 경고가 뜹니다(애플 개발자 서명이 없는 개인 앱).
   **시스템 설정 → 개인정보 보호 및 보안** 맨 아래에서 **그래도 열기**를 누르세요.
3. 첫 실행 안내에서 **손쉬운 사용 권한 켜기** → 시스템 설정에서 MenuBarTidy를 켭니다.
4. (선택) 실제 아이콘 모양을 보려면 `‹` 우클릭 → "실제 아이콘 모양 보기 (화면 기록 권한)".

## 사용법

- 메뉴바에 `│`(구분선)과 `‹`(버튼)이 생깁니다.
- **숨기기**: `⌘`를 누른 채 아이콘을 `│` **왼쪽**으로 끌어 놓으면 15초 뒤 자동으로 숨겨집니다.
- **`‹` 클릭**: 숨은 아이콘과 노치에 가린 아이콘이 아래로 펼쳐집니다. 누르면 그 앱 메뉴가 열립니다.
- **펼친 창에서 `⌘`+드래그**: 펼친 창 안의 순서를 바꿉니다(실제 메뉴바 순서는 그대로).
- **`‹` 우클릭 → 설정**: 좌클릭 기본 동작(아래로 / 옆으로), 15초 뒤 자동 숨김, 로그인 시 실행, 종료.

## 권한이 필요한 이유

| 권한 | 용도 |
|---|---|
| 손쉬운 사용 | 다른 앱의 메뉴바 아이콘 목록을 읽고, 펼친 창에서 누른 아이콘을 엽니다. |
| 화면 기록 (선택) | 펼친 창에 실제 메뉴바 아이콘 모양을 보여 주려고 아이콘만 캡처합니다. 저장하거나 전송하지 않습니다. |

네트워크 접속은 하지 않습니다.

## 알려진 한계

- 일부 앱 아이콘은 프로그램이 보내는 "누르기" 명령을 무시해서 펼친 창에서 열리지 않을 수 있습니다.
- 실제 메뉴바의 아이콘 순서는 바꾸지 않습니다. 직접 `⌘`+드래그로 옮기세요.
- macOS는 노치 왼쪽에 메뉴바 아이콘을 그리지 않아서, 노치에 가린 아이콘은 펼친 창으로 써야 합니다.

## 직접 빌드

Xcode(또는 Command Line Tools)가 필요합니다.

```bash
./build.sh        # 빌드 후 /Applications에 설치
./build.sh dist   # 배포용 dist/MenuBarTidy-<버전>.zip 생성
```

앱 아이콘은 `make_icon.swift`로 만듭니다. 키체인에 `MenuBarTidy Dev` 코드 서명 인증서가 있으면 그걸로 서명하고(재빌드해도 권한 유지), 없으면 임시(ad-hoc) 서명합니다.
